# PhraseLock — английские фразы на экране блокировки (Android)

Android-версия приложения для изучения английского: **фраза часа** всегда перед глазами.
На экране блокировки фраза висит как постоянное уведомление (в Android нет виджетов
на экране блокировки с версии 5.0 — Google их убрал, поэтому «вместо виджета» — уведомление).

## Что внутри

- 📱 **Приложение** (Kotlin + Jetpack Compose, Android 8.0+): фраза часа, каталог 400 фраз по 6 категориям (A1–B2) с поиском, избранное, «выучено».
- 🔔 **Постоянное уведомление** с текущей фразой + переводом: видно в шторке и на экране блокировки; обновляется раз в час (WorkManager) без интернета.
- 🎯 Фраза подбирается детерминированно из текущего часа — одинаковая всегда, интернет не нужен.

## Сборка и установка (всё через браузер + телефон)

1. На [github.com](https://github.com) создай **новый репозиторий** `PhraseLockAndroid` (Public — чтобы минуты Actions были бесплатными и без лимита, либо Private — тогда лимит на macOS/Linux-минуты, но Linux дешёвый).
2. Загрузи в него **содержимое этой папки** (не папку целиком и не архив): на странице репозитория → **Add file → Upload files** → перетащи всё, кроме `.github`.
3. Проверь наличие `.github/workflows/android.yml` в корне. Если его нет — **Add file → Create new file** → имя `.github/workflows/android.yml` → вставь содержимое файла из этого проекта → **Commit changes**.
4. Вкладка **Actions** → сборка **android-build** запустится сама (или нажми **Run workflow**). Она собирает `app-debug.apk`.
5. Зелёная галочка → открой запуск → **Artifacts** → скачай **PhraseLock-debug-apk** → распакуй zip → внутри `app-debug.apk`.
6. Передай APK на телефон (Telegram/USB/Google Drive). На телефоне открой файл → разреши **«Установка из неизвестных источников»** для того приложения, которым открываешь APK → **Установить**.
7. В приложении → вкладка **Настройки** → включи **«Уведомление с фразой»** → разреши уведомления → готово: фраза висит на экране блокировки.

Никаких подписей, сертификатов и 7-дневной протухшей просрочки: Android разрешает ставить APK напрямую.

## Как устроен код

```
app/src/main/assets/phrases.json   — 400 фраз, 6 категорий (тот же файл, что и в iOS-версии)
app/src/main/java/com/denie/phraselock/
    App.kt                         — точка входа, создаёт канал уведомлений
    MainActivity.kt                — экраны «Сегодня» / «Каталог» / «Настройки» (Compose)
    PhraseRepository.kt            — загрузка фраз, детерминированная «фраза часа» (splitmix64)
    FavoritesStore.kt              — избранное и «выучено» (SharedPreferences)
    NotificationHelper.kt          — постоянное уведомление с фразой
    PhraseScheduler.kt             — включение/выключение ежечасного обновления
    PhraseWorker.kt                — фоновая работа (WorkManager, раз в час)
.github/workflows/android.yml      — CI: сборка APK на ubuntu-latest
```

## Как менять

- **Добавить фразы**: `app/src/main/assets/phrases.json` (те же поля id/en/ru/category/level).
- **Частота уведомления**: сейчас раз в час (`PeriodicWorkRequestBuilder(1, TimeUnit.HOURS)`); Android всё равно может немного сдвигать период.
- **Иконка**: `app/src/main/res/drawable/ic_book.xml`, фон — `ic_launcher_background.xml`.
